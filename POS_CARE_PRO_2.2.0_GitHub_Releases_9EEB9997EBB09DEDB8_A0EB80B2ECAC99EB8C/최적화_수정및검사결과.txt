POS CARE PRO 2.1 최적화 변경 및 검사 결과
========================================
수정 범위: POS_CARE_PRO.hta만 수정했습니다. 나머지 파일은 원본 그대로 유지했습니다.

수정 사항
1. 앱 시작 시 로그인 화면만 먼저 표시하고, 로그인 전에 WMI/네트워크 확인을 실행하지 않도록 변경.
2. 로그인 후 CPU/메모리/디스크와 네트워크 상태 검사를 지연·분리 실행하며, 주기적 검사를 20초/45초로 낮추고 작업 중에는 건너뜀.
3. 전체 진단은 항목을 '검사 중'으로 먼저 표시하고 70ms 뒤 검사하도록 변경해 UI가 상태를 그릴 기회를 보장.
4. 자동 복구 시 COM 포트를 한 번에 5개 검사하지 않고 한 항목씩 진행 표시.
5. SFC/DISM을 무조건 연속 실행하지 않음. DISM CheckHealth에서 손상이 명확히 확인된 경우에만 RestoreHealth와 SFC를 실행.
6. DISM/SFC 작업은 백그라운드 프로세스로 실행하고 메인 화면 진행률/단계/로그를 주기적으로 갱신.
7. Windows 빠른 검사 25초, RestoreHealth/SFC 각각 180초, 전체 자동 복구 8분 제한. 시간 초과/판정 불명확을 성공으로 표시하지 않음.
8. 완료 상태 및 실패/확인 필요 건수를 메인 화면에 표시하고, 완료 팝업으로 화면을 가리지 않음.

검사 제한 고지
- JavaScript 문법 및 구조, 파일 구성, ZIP 무결성은 검사합니다.
- 이 실행 환경은 Windows HTA/ActiveX/WMI/DISM을 실행하지 못하므로 실제 POS PC에서의 WMI 지연 시간과 관리자/UAC 동작은 현장 실행 검증이 필요합니다.
