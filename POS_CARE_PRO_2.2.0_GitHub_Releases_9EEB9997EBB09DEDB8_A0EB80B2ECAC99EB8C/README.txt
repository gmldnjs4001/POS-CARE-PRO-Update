POS CARE PRO 2.1 | 현장 진단센터

프로그램 본체는 POS_CARE_PRO.hta입니다.
바탕화면 아이콘 생성.vbs를 실행하면 바탕화면에 진단하기 바로가기가 생성됩니다.
진단하기 바로가기는 Windows의 mshta.exe로 POS_CARE_PRO.hta를 직접 실행합니다.

기능 구성:
- 전체 진단 / 자동 복구 / 긴급 복구
- 블루스크린 긴급복구
- COM1~COM5 장치 진단
- 주변기기 진단
- 설정 / 업데이트
- 정보 / 로그 / 보고서

보안 실행 방식:
사용자 제작 EXE 런처를 포함하지 않아 Microsoft Defender SmartScreen의 '인식할 수 없는 앱' 경고가 발생하는 실행 경로를 제거했습니다.
