POS CARE PRO 업데이트 설정 (MYBOX ZIP 방식)

1. MYBOX에 'POS CARE PRO 업데이트' 폴더를 만듭니다.
2. 최신 프로그램 ZIP 파일 하나만 넣습니다.
   예: POS_CARE_PRO_2.2.0.zip 또는 POS_CARE_PRO_latest.zip
3. MYBOX Open API에서 개인 액세스 토큰(PAT)을 만듭니다.
4. 프로그램 설정에서 MYBOX 개인 액세스 토큰과 업데이트 폴더명을 저장합니다.
5. [MYBOX 연결 확인]을 눌러 확인합니다.
6. [업데이트] 버튼을 누르면 최신 ZIP 다운로드 -> 적용 -> 재실행됩니다.

중요: MYBOX ZIP 방식에서는 update_manifest.json을 만들 필요가 없습니다.
일반 HTTPS manifest 방식도 기존 호환 기능으로 남아 있습니다.
