POS CARE PRO 2.2.0 — GitHub Releases 자동 업데이트 설정 안내

이 버전은 GitHub의 공개 Releases API 주소를 이용해 최신 버전을 확인하고 ZIP을 내려받도록 수정되어 있습니다.

1. GitHub에서 새 저장소 만들기
   - https://github.com/ 접속 후 로그인
   - 오른쪽 위 + 버튼 > New repository
   - Repository name 예: POS-CARE-PRO-Update
   - Public 선택 (Private는 이 간단한 무토큰 방식에서 사용하지 마세요)
   - Create repository 클릭

2. GitHub에 프로그램 ZIP 올리기
   - 저장소 페이지에서 Releases를 찾습니다. 안 보이면 오른쪽 Releases 또는 /releases/new 으로 이동합니다.
   - Draft a new release 클릭
   - Choose a tag에 v2.2.0 입력 후 Create new tag on publish 선택
   - Release title: POS CARE PRO 2.2.0
   - 설명을 입력합니다.
   - Attach binaries by dropping them here 또는 파일 선택으로 이 ZIP 패키지를 첨부합니다.
   - ZIP 파일은 POS_CARE_PRO_2.2.0_GitHub_Releases_자동업데이트_정밀검사완료.zip처럼 .zip으로 끝나야 합니다.
   - Publish release 클릭

3. 업데이트 주소 만들기
   - 계정명이 example, 저장소 이름이 POS-CARE-PRO-Update라면 주소는
     https://api.github.com/repos/example/POS-CARE-PRO-Update/releases/latest
   - 위 주소에서 example을 본인의 GitHub 계정명으로 바꿉니다.
   - 저장소 이름은 실제로 만든 이름과 대소문자/하이픈까지 똑같아야 합니다.
   - https://github.com/ 주소나 저장소의 일반 웹페이지 주소를 넣지 마세요.

4. POS CARE PRO에서 입력
   - 설정을 열고 '업데이트 서버 주소 (GitHub Releases)' 칸에 위 API 주소를 붙여넣습니다.
   - MYBOX 개인 액세스 토큰 칸은 비워둡니다. 이미 남아 있는 예전 토큰이 있더라도 GitHub API 주소를 넣으면 GitHub 방식이 우선됩니다.
   - '업데이트 확인' 버튼을 눌러 최신 Release를 찾는지 확인합니다.
   - 더 높은 버전의 Release가 있으면 업데이트 가능 메시지가 나옵니다.
   - 업데이트 적용 시 프로그램 ZIP을 다운로드하고 기존 폴더에 적용한 뒤 프로그램을 닫습니다.

5. 다음 버전 배포
   - 새 버전 ZIP을 같은 저장소의 새 Release에 첨부합니다.
   - 태그를 v2.3.0처럼 더 높은 버전으로 만듭니다.
   - 이전 Release를 덮어쓰지 말고 새 Release를 발행하세요.
   - 업데이터는 최신 Release의 첨부 파일 중 POS_CARE_PRO 이름을 가진 ZIP을 우선 선택합니다.

주의
- 이 방식은 공개 GitHub 저장소와 공개 Release를 사용합니다. 비공개 저장소는 인증 설정이 추가로 필요합니다.
- 저장소가 없거나 비공개이거나 Release에 ZIP 첨부가 없으면 HTTP 404 또는 ZIP 누락 안내가 표시될 수 있습니다.
- GitHub 방식의 첫 적용은 기존에 설치된 구버전이 자동 적용 코드를 갖고 있지 않을 수 있으므로 이 패키지를 한 번 수동으로 압축 해제/덮어쓰기 설치한 뒤 사용하세요.
- 업데이트 ZIP의 최상위에는 POS_CARE_PRO.hta와 update_runner.vbs가 있어야 합니다. 하위 폴더 안에 전체 프로그램이 한 번 더 중첩되게 압축하지 마세요.
