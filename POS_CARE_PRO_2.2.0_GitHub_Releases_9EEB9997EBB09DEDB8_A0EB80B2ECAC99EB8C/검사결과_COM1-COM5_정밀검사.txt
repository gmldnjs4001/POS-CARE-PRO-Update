POS CARE PRO 2.1 COM1~COM5 진단 수정 및 정밀검사 결과
====================================================

수정 범위
- 기존 기능은 유지하고 06~10번 진단 항목만 COM1~COM5 기준으로 변경
- 06 = COM1
- 07 = COM2
- 08 = COM3
- 09 = COM4
- 10 = COM5

연결 판정 변경
- 단순히 Windows에 COM 포트가 존재하는 것만으로 '기기 연결'로 판정하지 않음
- COM 포트가 존재하고 오류 코드가 없는지 먼저 확인
- 이후 실제 COM 상태 신호(CTS/DSR/CD)를 짧은 시간 동안 확인
- 실제 상태 신호가 확인되면: '기기 연결'
- 포트가 없거나 실제 상태 신호가 확인되지 않으면: '기기 연결 안됨'
- COM 검사 중 콘솔창은 표시하지 않음
