POS CARE PRO - 네이버 MYBOX 자동 업데이트 설정

[가장 쉬운 방법]
1. MYBOX에 'POS CARE PRO 업데이트' 폴더를 만듭니다.
2. 이 폴더에 최신 프로그램 ZIP 파일 하나만 넣습니다.
   - 권장: POS_CARE_PRO_2.2.0.zip
   - 또는: POS_CARE_PRO_latest.zip
3. MYBOX Open API에서 개인 액세스 토큰(PAT)을 발급합니다.
4. POS CARE PRO -> 설정에서 다음을 입력합니다.
   - MYBOX 개인 액세스 토큰: mbx_pat_...
   - MYBOX 업데이트 폴더명: POS CARE PRO 업데이트
   - 업데이트 서버 주소: MYBOX 사용 시 비워둘 수 있습니다.
5. [MYBOX 연결 확인]을 눌러 ZIP 파일이 보이는지 확인합니다.
6. 이후 [업데이트] 버튼을 누르면 최신 ZIP을 자동 다운로드하고 적용합니다.

update_manifest.json은 필요하지 않습니다.
프로그램이 MYBOX API로 폴더를 조회하여 가장 최근의 POS_CARE_PRO*.zip 파일을 찾습니다.
버전이 파일명에 들어 있으면(예: POS_CARE_PRO_2.2.0.zip) 버전 번호를 비교합니다.
파일명이 latest인 경우에는 ZIP 파일 수정 시각을 현재 프로그램 파일과 비교하여 업데이트 여부를 판단합니다.

주의: 개인 액세스 토큰은 다른 사람에게 공유하지 마세요.
