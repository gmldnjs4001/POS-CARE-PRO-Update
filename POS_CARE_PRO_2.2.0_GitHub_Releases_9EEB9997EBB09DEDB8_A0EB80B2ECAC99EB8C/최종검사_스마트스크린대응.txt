POS CARE PRO 2.1 최종 실행/SmartScreen 검사
===========================================

[실행 구조]
- 사용자 제작 EXE 런처: 제거
- 바탕화면 생성: VBS -> WScript.Shell.CreateShortcut
- 진단하기 실행: .lnk -> Windows mshta.exe -> POS_CARE_PRO.hta
- 검정색 CMD: 사용하지 않음

[핵심 기능 보존]
- POS_CARE_PRO.hta: 원본과 해시 비교로 동일
- COM1~COM5 표시: 확인
- 업데이트 버튼/autoUpdate: 확인
- 블루스크린 복구 함수: 확인

[안전성]
- 사용자 제작 EXE는 배포본에서 제외되었습니다.
- SmartScreen은 코드로 끄는 대신, SmartScreen 경고 대상인 unsigned EXE 실행 경로를 제거했습니다.

[정적 검사]
- ZIP 무결성: PASS
- 압축 후 재해제: PASS
- UTF-8 파일명: PASS
- VBS UTF-16LE+BOM: PASS
- HTA 스크립트 균형 검사: PASS
