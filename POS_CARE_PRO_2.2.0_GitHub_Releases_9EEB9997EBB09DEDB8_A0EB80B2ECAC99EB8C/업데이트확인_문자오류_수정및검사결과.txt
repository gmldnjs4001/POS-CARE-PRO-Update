POS CARE PRO 2.1 - 업데이트 확인 문자 오류 수정 및 검사 결과

수정 사항
1. MYBOX 개인 액세스 토큰이 입력되어 있으면, 레지스트리에 남아 있던 이전 업데이트 서버 주소 대신 MYBOX를 우선 사용합니다.
2. 업데이트 주소 앞뒤의 BOM/따옴표/복사 시 들어갈 수 있는 줄바꿈과 탭을 정리하고, HTTP/HTTPS 주소인지 확인합니다.
3. 업데이트 서버 응답의 UTF-8 BOM을 제거한 뒤 JSON으로 읽도록 수정했습니다.
4. 서버 응답이 JSON이 아니라 HTML 로그인/오류 페이지인 경우 원인을 알려주는 안내를 표시합니다.
5. JSON이 잘못되었거나 version 항목이 없는 경우, 일반적인 '유효하지 않은 문자입니다' 대신 더 구체적인 오류 메시지를 표시합니다.
6. 기존 POS CARE PRO 진단/복구 최적화, COM1~COM5 진단, 로그인, 업데이트 실행기 등은 그대로 유지했습니다.

검사
- HTA 스크립트 구문 검사: 통과
- 업데이트 확인 경로 시뮬레이션: 통과
- MYBOX 토큰 사용 시 기존 URL 우선순위 오류 테스트: 통과
- UTF-8 BOM/따옴표 포함 URL 처리 테스트: 통과
- JSON 응답 처리 테스트: 통과
- HTML 응답 진단 메시지 테스트: 통과
- ZIP CRC 검사 및 재압축 후 재추출 검사: 통과

주의
실제 Windows HTA + WinHTTP + 네이버 MYBOX API 연결은 이 환경에서 사용자 PC의 토큰/네트워크로 직접 실행할 수 없습니다. 실제 PC 연결 성공 여부는 해당 PC에서 확인해야 합니다.
