POS CARE PRO 2.1 COM1~COM5 실제 장치 연결 판정 개선 - 정밀 검사 결과
============================================================

수정 범위
- 06 = COM1
- 07 = COM2
- 08 = COM3
- 09 = COM4
- 10 = COM5
- 기존 기능은 유지하고 COM1~COM5 연결 판정 및 주변기기 진단의 잘못된 연결/미연결 판정만 수정

핵심 원인
1. 기존 진단은 CTS/DSR/CD 신호만 보고 실제 장치를 판정하여, POS 프로그램이 이미 COM 포트를 사용 중인 실제 장치를 '연결 안됨'으로 오판할 수 있었음.
2. 기존 주변기기 진단은 Windows PnP에 COM 포트가 존재하고 오류 코드가 0이면 케이블/변환기만 연결되어도 '연결 정상'으로 오판할 수 있었음.

수정 내용
- Windows PnP 오류/상태 우선 확인
- 장치명이 일반 USB-Serial/CH340/CH341/CP210/FTDI/PL2303/Prolific 등 범용 변환기인 경우에만 짧은 비파괴 COM 상태 확인
- CTS/DSR/CD 또는 수신 대기 데이터가 확인되면 '기기 연결'
- POS 등 다른 프로그램이 COM 포트를 이미 사용 중이면 '기기 연결'로 판단하여 실제 현장 장치를 놓치지 않음
- 범용 변환기만 있고 신호/수신 데이터가 없으면 '기기 연결 안됨'
- PnP 장치 자체가 없으면 '기기 연결 안됨'
- PnP 오류 상태이면 '기기 연결 오류'
- 주변기기 진단도 동일한 판정 로직 적용
- PowerShell은 숨김 실행되어 별도 콘솔 팝업 없음

중요한 한계
일반적인 RS-232/USB-Serial 환경에서는 운영체제만으로 'USB-Serial 변환기 끝에 물리적 기기가 연결되었는지'를 100% 판별할 수 없습니다. 따라서 범용 변환기만 있는 경우 실제 신호/수신 데이터/포트 사용 상태를 함께 판단하도록 보수적으로 구성했습니다.
